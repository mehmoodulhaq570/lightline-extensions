# C and C++ Snippets

Snippets for the C and C++ you type in a file you're about to run: `c.json` for `.c` and `.h` files, `c++.json` for `.cpp`, `.hpp`, `.cc` and the rest.

In LightLine, type a prefix and press `Ctrl+Space`, then `Tab` to move between the placeholders.

| C | C++ |
| --- | --- |
| `main`, `maina` (with argc/argv) | `main`, `maina` |
| `inc`, `incl` (a local header), `guard` (include guard) | `inc`, `once` (`#pragma once`), `ns` (namespace) |
| `func`, `if`, `ife`, `for`, `fori` (over an array), `while`, `do`, `switch` | `class`, `struct`, `forr` (range for), `fori`, `if`, `ife` |
| `struct`, `tstruct` (typedef), `enum` | `cout`, `cin`, `vec`, `map`, `uptr` (`make_unique`) |
| `printf`, `scanf` (checked), `malloc` (NULL check), `fopen` (error check) | `lambda`, `tmpl` (template), `try`, `test` (main with an assert) |
